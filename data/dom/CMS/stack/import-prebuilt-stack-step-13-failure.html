Kickstart Angular

Contentstack Kickstarts are the minimum you need to connect to Contentstack’s platform quickly. Out of the box you get Angular, the Contentstack SDK fully configured and visual building. Kickstarts use agnostic tooling in the context of you favorite framework. In this case Angular.

  1. Import Starter to Stack
    Import Starter to Stack

    Give the stack where you want to install this Starter app a name. This is where CS would import the content types, entries etc. to the stack and publish it to the required environment.

  2. Deploy
    Deploy

    To deploy your Starter app, you can connect your account with Launch.

  3. Setup Complete!
    Setup Complete!

    We will share some links that will be helpful for you.
